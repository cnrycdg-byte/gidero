# Gidero

**Fişi çek, vergini kurtar.**

Gidero, çalışanların masraf fişlerini telefonla çekip gönderdiği, şirketin kendi onay akışını kurduğu,
vergi risklerinin fiş girilirken uyarıldığı ve kayıtların Logo, Mikro, Luca, Zirve, ETA ve Paraşüt'e
aktarıldığı bir masraf yönetim uygulamasıdır. Şirketler ve muhasebe büroları için iki planla sunulur.

## Durum

Geliştirme başlangıcı. Yol haritası:

1. Altyapı: veri modeli, yetki, fiş okuma (hafta 2–6)
2. Web paneli (hafta 5–10)
3. Mobil uygulama (hafta 7–12)
4. Muhasebe aktarımı (hafta 10–13)
5. Pilot: 3 şirket + 1 büro (hafta 13–19)
6. Satışa açılış (hafta ~21)
